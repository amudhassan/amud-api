property_public_id

date_to=YYYY-MM-DD
currency_code=TZS

AUTHORIZATION
- Admin: global scope.
- Owner user financial endpoints: can_manage_finances.
- Occupancy/lease endpoints: can_manage_properties.
- Maintenance endpoints: can_view_maintenance_requests.
- Dashboard: section-by-section authorization.
- Tenant users: no management reporting access.

EXPECTED HTTP STATUS
200 success
400 validation failure
403 insufficient reporting permission
404 inaccessible/not-found selected owner/property
