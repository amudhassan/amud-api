REPORTS & DASHBOARD - FAST LOCAL SMOKE PLAN
===========================================

Use:
Authorization: Bearer <ACCESS_TOKEN>

1. Admin:
GET /api/reports/financial/summary
Expected 200.

2. Admin:
GET /api/reports/occupancy
Expected 200.

3. Admin:
GET /api/reports/leases/expiring?days=30
Expected 200.

4. Admin:
GET /api/reports/maintenance/summary
Expected 200.

5. Admin:
GET /api/reports/dashboard
Expected 200.

6. Admin:
GET /api/reports/financial/revenue/export?format=csv&period=monthly
Expected 200 and text/csv.

7. Admin:
GET /api/reports/dashboard/export?format=pdf
Expected 200 and application/pdf.

8. Owner user with finance permission:
GET /api/reports/financial/summary
Expected 200 and owner isolation.

9. Owner user without finance permission:
GET /api/reports/financial/summary
Expected 403.

10. Owner user with property permission:
GET /api/reports/occupancy
Expected 200 and owner isolation.

11. Owner user with maintenance read permission:
GET /api/reports/maintenance/summary
Expected 200 and owner isolation.

12. Tenant-only user:
GET /api/reports/dashboard
Expected 403.

13. Export audit:
After a successful export, query report_exports in pgAdmin.
Expected one immutable audit row.
